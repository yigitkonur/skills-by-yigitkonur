# Canonical Examples Cluster

*Read this first to understand how to navigate real working examples.*

This cluster documents canonical examples from `/tmp/mcp-use-beta/docs/typescript/server/examples.mdx` — working MCP servers you can connect to, clone, and remix. Each example is live and deployed on mcp-use Cloud.

## Quick start

1. **Try a live example:** Pick an example below, copy its demo URL, and open it in the [Inspector](/inspector/index).
2. **Clone to customize:** Each example links to its GitHub source. Clone, edit tools/views, and re-deploy.
3. **Inventory:** If you need a pattern not listed, see `03-example-inventory.md` for the complete grounded list.

## What's included

- **01-chart-builder.md** — Create charts from natural language (tool: `create-chart`). Canonical for structured output + views.
- **02-diagram-builder.md** — Build diagrams conversationally (tools: `create-diagram`, `edit-diagram`). Canonical for multi-tool workflows.
- **03-example-inventory.md** — Full grounded list from examples.mdx with live endpoints, GitHub sources, and tool names. Start here if looking for a specific pattern.

## How to read each example

Each example file shows:
- What the example does
- The live MCP endpoint URL (paste into Inspector under "Direct" transport)
- The GitHub source repo (clone to customize)
- Key tools exposed
- Deploy link to self-host

The Inspector lets you call tools before you commit to cloning.
