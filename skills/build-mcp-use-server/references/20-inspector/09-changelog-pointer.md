# Changelog

*Read this when checking Inspector version history and release notes.*

The Inspector receives regular updates paired with mcp-use releases. The latest versions include:

- **v12.0.0** (July 2026): Hosted OAuth reliability fixes, paired with mcp-use v1.34.0
- **v11.0.0** (June 2026): MCP Apps as primary widget runtime, Auto connections with proxy fallback, host context styles
- **v10.0.1** (June 2026): Hosted localhost chat fallback, chat scroll helper
- **v10.0.0** (June 2026): Paired with mcp-use v1.32.0
- **v9.0.0** (June 2026): OAuth credential cleanup, paired with mcp-use v1.31.0

The npm latest version (v12.x) is significantly different from the beta line (v20.x). When troubleshooting, check which version you are running: the Inspector displays its version in the browser console or via `npm info @mcp-use/inspector`.

For a complete changelog with all releases and detailed fixes, see the [Inspector changelog](https://docs.mcp-use.com/inspector/changelog).
