# Test Case: TC-VIS-06 - Stage 1 Synthesized Answer Inspector & In-Card Engine Tabs

## 1. Case ID and Purpose
- **Case ID:** `TC-VIS-06`
- **Module:** Answer Engine Insights (`assets/aei.js`, `assets/aei.css`)
- **Parent Contract:** Spec 11 (Answer Engine Insights Multi-Platform Visibility Architecture)
- **Traceability:** Maps to Source Scenarios `VIS-10`, `VIS-11`, and `VIS-22`
- **Purpose:** Verify that Stage 1 of the Generative Retrieval Pipeline (`.aei-answer-box`) renders the synthesized AI model answer, displays model metadata badges (e.g. `gpt-4o`, `claude-3-5-sonnet`), displays position rank badges (`.aei-pos-badge`), indicates web search retrieval status (green dot for live search, amber for parametric), highlights brand mentions, and re-renders dynamically when toggling in-card engine selector tabs (`button.aei-pipe-engine-tab`).

---

## 2. Tester Brief
The tester or automated agent examines the right-hand Studio detail pane (`.aei-studio-detail.card`):
1. In Stage 1, verify the engine selector tab rail (`.aei-pipe-engine-tab`).
2. Confirm the active answer box displays:
   - Header with engine icon, platform name, and model badge (`.chip.mono.small`).
   - Position rank badge (`#1` for top mention, `#2+` for lower positions).
   - Web search status chip (e.g. `● Web Search (Live)` or `● Parametric`).
3. Click through different in-card engine selector tabs (e.g. `Perplexity`, `Claude`, `Gemini`) and verify:
   - The selected tab receives the active state.
   - The answer text updates to the response generated by that specific engine.
   - The model badge updates to reflect the engine's model version.
   - Brand mentions in the new answer are highlighted accordingly.

## 5. Visual Checks
1. **Answer Box Container:** `.aei-answer-box` is styled with card elevation, soft borders, and comfortable line spacing (`line-height: 1.6`).
2. **Brand Mention Colors:**
   - `.aei-mention-brand`: Highlighted with light green background and dark green text (`var(--green)`).
   - `.aei-mention-rival`: Highlighted with light amber/gray background and contrasting text (`var(--ink-2)`).
3. **Position Rank Badge:**
   - `.pos-won`: Bright green pill with bold `#1`.
   - `.pos-rival`: Subtle neutral pill for secondary rankings (`#2`, `#3`).
4. **Markdown Typography:** Proper rendering of bullet points, bold text, and paragraphs inside `.markdown-body`.

---

## 6. Data and Network Checks
1. **Engine Selection State:**
   ```js
   assert(window.aeiState.studioActiveEngine === targetEngine, "Active engine must update");
   ```
2. **Highlighting Integrity:** Ensure `highlightAnswerText()` executes without stripping markdown tags or leaking unescaped HTML.
3. **Model Badge Text:** Verify `a.model || a.modelName` matches the active platform execution record.
