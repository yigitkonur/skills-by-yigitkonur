# Execute Site-Wide Performance Audits Using Unlighthouse Against Preview Server

> **Context:** Auditing & Next.js Migration | **Impact:** High | **Target:** Astro 4 / Astro 5

## 1. Why We Do This

Auditing only the homepage with Lighthouse creates a false sense of security. Performance regressions often lurk in paginated blog archives, product pages with heavy client islands, or dynamic MDX content routes. Unlighthouse discovers all site routes via `@astrojs/sitemap` and audits every page in parallel using headless Lighthouse, generating a comprehensive site-wide dashboard of Core Web Vitals, accessibility scores, and SEO metrics.

## 2. How It Differs From Classic React / Next.js

In Next.js, auditing hundreds of pages often takes hours or causes memory exhaustion due to heavy server-side React hydration on every page. In Astro, static routes are pre-rendered pure HTML; crawling with Unlighthouse against `astro preview` completes in minutes with consistent, sub-second TTFB and near-perfect 100/100 Lighthouse scores across the entire route tree.

## 3. Common Mistakes & Anti-Patterns

Scanning the live development server (`http://localhost:4321`) while Vite is running, which produces false failures due to unminified dev modules, or auditing without generating a sitemap, which forces the crawler to guess routes through page links alone.

### ❌ Bad Practice / Anti-Pattern

```bash
# Auditing without sitemap against development server (INCORRECT)
pnpm dev &
# Lacks sitemap integration; audits unminified dev server with HMR overhead
npx unlighthouse --site http://localhost:4321
```

### ✅ Best Practice / Idiomatic

```ts
// unlighthouse.config.ts
import { defineUnlighthouseConfig } from 'unlighthouse/config'

export default defineUnlighthouseConfig({
  site: 'http://localhost:4321',
  scanner: {
    // Automatically uses dist/sitemap-index.xml generated by @astrojs/sitemap
    sitemap: ['http://localhost:4321/sitemap-index.xml'],
    samples: 1,
  },
  ci: {
    budget: {
      performance: 95,
      accessibility: 98,
      'best-practices': 95,
      seo: 98,
    },
  },
})
```

```bash
# Production preview audit script
pnpm build
pnpm preview &
npx unlighthouse --config-file unlighthouse.config.ts
```

## 4. Verification & Audit

Run Unlighthouse in CI assertion mode to enforce site-wide score thresholds:

```bash
# Exits with non-zero status if any page falls below configured performance budgets
npx unlighthouse-ci --site http://localhost:4321 --budget.performance 95
```
