# Mission Brief: Broken Anchors (#hash) & Deep-Link Fragment Integrity Audit

## 3.0 Skills / Tools: view_file, run_command.

## 3.1 Context Block

In long-form content (articles, guides, checklists, API docs), internal navigation relies on fragment identifiers (e.g., `/resources/seo-guide#technical-audit`).
In Astro 5's `<ClientRouter />` architecture, soft navigations to fragment links trigger the `astro:before-swap` and `astro:after-swap` lifecycle. The client router automatically queries the target element ID and scrolls it into view.
However, if a heading's text changes or Sätteri's Rust HAST processor slugifies it differently (e.g., `heading-technical-audit` vs `technical-audit`), the link silently breaks: the router swaps the document but cannot find the anchor target, leaving the user stranded.

Key Astro Best Practice contracts for Deep-Link Fragment Integrity:

1. **ClientRouter Hash Navigation & Scroll Restoration**: Standard internal `<a>` tags with hash fragments (`href="#section"` or `href="/guide#section"`) are intercepted by `<ClientRouter />`. Target elements must exist at the moment `astro:after-swap` executes.
2. **Per-Link Reload Opt-Out**: When deep linking to legacy external tools or isolated non-SPA landing pages, links must declare `data-astro-reload` to bypass client routing.
3. **Deterministic Heading ID Parity**: Table of Contents (TOC) generators and inline markdown cross-references must strictly match the ID generated by `config/markdown-plugins/heading-id-parity.mjs`.
4. **Zero-Broken Anchor Discipline**: Every internal `#hash` link must point to a verified, unique ID attribute rendered in the destination DOM tree.

Astro Architectural & Best Practice Rules:

- **Execute Site-Wide Performance Audits Using Unlighthouse Against Preview Server ([08-site-wide-crawling-with-unlighthouse.md](../../best-practices/10-auditing-testing-and-nextjs-migration/08-site-wide-crawling-with-unlighthouse.md))**: Sweep all rendered routes with automated crawling to detect broken deep-links, orphaned fragment hashes, and 404 targets across all content collections (`ASTRO-BP-10-08`).
- **Prevent Cumulative Layout Shift (CLS) Across Media and Islands ([16-prevent-cumulative-layout-shift-cls.md](../../best-practices/09-performance-prefetch-and-transitions/16-prevent-cumulative-layout-shift-cls.md))**: Smooth scroll restoration to fragment targets requires stable layout geometry; unconstrained dynamic images or late-hydrating islands shift anchor positions after scroll restoration completes (`ASTRO-BP-09-16`).
- **Eliminate Total Blocking Time (TBT) and Optimize INP Under 200ms ([15-eliminate-total-blocking-time-tbt-and-optimize-inp.md](../../best-practices/09-performance-prefetch-and-transitions/15-eliminate-total-blocking-time-tbt-and-optimize-inp.md))**: Intercepting anchor clicks must not trigger synchronous main-thread blocking tasks during scroll restoration (`ASTRO-BP-09-15`).
- **Protect Authenticated Routes Server-Side via `context.cookies` and `context.redirect` ([06-auth-guard-session-validation.md](../../best-practices/06-middleware-and-auth/06-auth-guard-session-validation.md))**: Deep links pointing to authenticated sections must be guarded server-side to prevent fragment execution before authentication validation (`ASTRO-BP-06-06`).
- **Compose i18n Routing Before Auth Guards to Handle Localized Protected Paths ([16-i18n-and-multilingual-auth-composition.md](../../best-practices/06-middleware-and-auth/16-i18n-and-multilingual-auth-composition.md))**: Multilingual deep-link fragments (`/tr/rehber#bolum-1`) must preserve the locale prefix during router transitions (`ASTRO-BP-06-16`).

```typescript
// scripts/audits/check-fragment-integrity.ts
// ✅ Idiomatic: Automated build-time AST crawler validating all fragment targets:
import { readFileSync, readdirSync } from 'node:fs'
import { parse } from 'node-html-parser'

export function validateFragmentIntegrity(distDir: string) {
  const htmlFiles = readdirSync(distDir, { recursive: true }).filter((f) =>
    String(f).endsWith('.html'),
  )
  const brokenLinks: { file: string; hash: string }[] = []

  for (const file of htmlFiles) {
    const content = readFileSync(`${distDir}/${file}`, 'utf-8')
    const root = parse(content)
    const anchors = root.querySelectorAll('a[href*="#"]')

    for (const a of anchors) {
      const href = a.getAttribute('href') || ''
      const [path, hash] = href.split('#')
      if (hash && (!path || path === '' || path === file)) {
        const target = root.getElementById(hash)
        if (!target) {
          brokenLinks.push({ file: String(file), hash })
        }
      }
    }
  }
  return brokenLinks
}
```
